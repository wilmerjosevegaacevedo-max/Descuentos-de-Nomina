# 🌐 Frontend — Dashboard Web RPA LAD-6819

Carpeta dedicada a la interfaz web (Next.js / React + TypeScript + Firebase).

## 🚀 Comandos de Desarrollo

```powershell
cd frontend
npm install
npm run dev
```

## 🔗 Variables de Entorno (`frontend/.env.local`)

Configura las credenciales públicas de Firebase y la URL de la API FastAPI (`http://127.0.0.1:8000`) en un archivo `.env.local` dentro de esta carpeta.
